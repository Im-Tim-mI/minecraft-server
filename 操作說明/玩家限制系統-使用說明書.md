# 玩家限制系統 使用說明書

## 📋 系統概述

玩家限制系統是一個基於 Skript 的伺服器管理工具，用於限制違規玩家的遊戲行為。被限制的玩家只能移動和聊天，無法進行任何其他交互。

### 特色功能

- 支援基岩版玩家（`.` 開頭的名稱）
- 支援使用玩家名稱或 UUID 進行操作
- 全服自動廣播封禁/解封訊息
- 被限制玩家登入時自動通知
- 完整阻止所有遊戲交互

---

## 🔧 指令一覽

| 指令 | 功能 | 權限 |
|------|------|------|
| `/限制 <玩家> <原因>` | 限制指定玩家 | OP |
| `/限制uuid <UUID> <原因>` | 使用 UUID 限制玩家 | OP |
| `/解除限制 <玩家>` | 解除玩家限制 | OP |
| `/解除限制uuid <UUID>` | 使用 UUID 解除限制 | OP |
| `/限制狀態 <玩家或UUID>` | 查看玩家限制資訊 | OP |
| `/限制列表` | 查看所有被限制的玩家 | OP |

## 📖 詳細使用方法

### 1. 限制玩家

#### 方法一：使用玩家名稱
```
/限制 <玩家名稱> <限制原因>
```

**範例：**
```
/限制 Steve 惡意破壞建築
/限制 .AaroN341672 群眾投票封禁
```

> ⚠️ **注意：** 基岩版玩家名稱前有 `.`（點號），如果系統找不到玩家，請改用 UUID 方式。

#### 方法二：使用 UUID（推薦用於基岩版玩家）

**步驟 1：查詢玩家 UUID**
```
/seen <玩家名稱>
```

**輸出範例：**
```
玩家 .AaroN341672 在 12 小時前已離線。
 - UUID：00000000-0000-0000-0009-01f360355d8d
 - IP 位址：106.1.90.236
```

**步驟 2：使用 UUID 限制**
```
/限制uuid 00000000-0000-0000-0009-01f360355d8d 群眾投票封禁
```

---

### 2. 解除限制

#### 方法一：使用玩家名稱
```
/解除限制 <玩家名稱>
```

**範例：**
```
/解除限制 Steve
```

#### 方法二：使用 UUID
```
/解除限制uuid <UUID>
```

**範例：**
```
/解除限制uuid 00000000-0000-0000-0009-01f360355d8d
```

---

### 3. 查看限制資訊

#### 查看單一玩家狀態
```
/限制狀態 <玩家名稱或UUID>
```

**輸出範例：**
```
[限制系統] ===== 限制資訊 =====
[限制系統] 玩家：.wenching913
[限制系統] UUID：00000000-0000-0000-0009-01ffd3d67a05
[限制系統] 原因：群眾投票封禁，破壞者
[限制系統] 執行者：rr901037
[限制系統] 時間：2026/04/07 03:00
```

#### 查看所有被限制的玩家
```
/限制列表
```

**輸出範例：**
```
[限制系統] ===== 被限制的玩家 =====
1. .wenching913
   UUID：00000000-0000-0000-0009-01ffd3d67a05
   原因：群眾投票封禁，破壞者
2. .AaroN341672
   UUID：00000000-0000-0000-0009-01f360355d8d
   原因：協助破壞者
[限制系統] 共 2 位玩家被限制。
```

## 🔍 常見問題

### Q1：找不到基岩版玩家怎麼辦？

**A：** 使用 `/seen <玩家名稱>` 查詢 UUID，然後使用 `/限制uuid` 指令。

```
/seen .AaroN341672
/限制uuid 00000000-0000-0000-0009-01f360355d8d 破壞建築
```

### Q2：限制原因可以包含空格嗎？

**A：** 不建議。如需多個詞彙，請用底線或逗號連接：
```
/限制 Steve 群眾投票封禁，協助破壞者
/限制 Steve 群眾投票封禁_協助破壞者
```

### Q3：如何重新載入腳本？

**A：** 使用以下指令：
```
/sk reload freeze-player
```

### Q4：限制資料儲存在哪裡？

**A：** 儲存在 Skript 的變數檔案中：
```
~/minecraft-server/plugins/Skript/variables.csv
```

### Q5：伺服器重啟後限制還在嗎？

**A：** 是的，限制資料會永久保存，直到手動解除。

## 🔗 相關權限（LuckPerms）

系統會自動將被限制的玩家加入 `frozen` 群組。

### frozen 群組權限設定

```bash
# 建立群組
/lp creategroup frozen
/lp group frozen setweight 100

# 禁止建築與交互
/lp group frozen permission set essentials.build false
/lp group frozen permission set worldguard.region.bypass.* false

# 禁止傳送
/lp group frozen permission set essentials.tp false
/lp group frozen permission set essentials.tpa false
/lp group frozen permission set essentials.home false
/lp group frozen permission set essentials.spawn false
```
